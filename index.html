加入团队第 2 / 11 步 · 约 10–15 分钟

准备你的 GitHub 身份

GitHub 用来共享代码和公司流程，也是你加入公司组织的身份。

已有 GitHub 账号？直接检查两步验证和恢复码，满足完成标准就可以继续。

1. 注册并验证邮箱

  1. 打开 github.com/signup。
  2. 依次填：邮箱（和引路人确认过的邮箱）、密码（按网页要求设置，并存进密码管理器）、用户名。用户名以后会公开显示、也是同事认你的名字，建议用名字拼音，只能用字母、数字和连字符。
  3. 它会让你做一个"我不是机器人"的小游戏，按提示完成。
  4. 去邮箱收一封验证码邮件，把码填回去。问你几个偏好问题，随便选或跳过。
查看图示：GitHub 登录页

2. 开启两步验证，并保存恢复码

请先完成这项账号保护，再申请加入公司。手机上准备 Google Authenticator、Microsoft Authenticator，或你已有的支持一次性密码的验证器。

查看图示：GitHub 开两步验证的四个画面
  1. 登录后打开 github.com/settings/security，找到 Two-factor authentication，点绿色按钮 Enable two-factor authentication。
  2. 它显示一个二维码。打开手机上的验证器 app，点"＋"或"扫码添加"，对准电脑屏幕扫。扫完 app 里会多出一行 GitHub，下面是 6 位数字。
  3. 把 app 上此刻显示的 6 位数字填进网页的输入框，点 Continue。数字每 30 秒变一次，快到期就等下一组。
  4. 它给你一页 Recovery codes（恢复码）。点 Download 或 Copy，存进密码管理器或一个安全的地方。无法使用验证器时，可以用恢复码恢复访问。不要发给别人，也不要只截图放相册。然后点确认完成。
完成标准：回到 settings/security 页，Two-factor authentication 一栏显示 Enabled。再记住你的用户名，之后绑定 bot 和终端时，要使用同一个账号。

卡住：验证码总提示错误，多半是手机时间不准，去手机设置里把时间改成自动获取。

准备工作环境第 4 / 11 步 · 约 15–30 分钟

装好三个基础工具

Git 记录修改，Node.js 运行工具，GitHub CLI（gh）连接你的账号。

先在上方选择安装用的电脑系统，即可看到对应命令。
查看图示：终端窗口示意

macOS

  1. 打开"终端"：按 ⌘ + 空格，输入 终端，回车。出现一个黑底或白底的窗口。
  2. 装 Homebrew（macOS 上装软件的工具）。点下面的"复制"，回到终端 ⌘ + V 粘贴，回车： 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    它会要你的电脑登录密码，输入时屏幕不显示任何字符，这是正常的，输完回车。中途可能弹窗让你装"命令行开发者工具"，点安装，等它装完（可能十几分钟）。安装结束后，按终端中 Next steps 的提示执行命令，把 Homebrew 加入 PATH；再打开一个新终端。
  3. 安装 Git 和 GitHub CLI： 
    brew install git gh
  4. 打开 Node.js 下载页 ↗，选择标注 LTS 的版本与 macOS，下载 .pkg 安装包，双击完成安装。

Windows

  1. 打开 PowerShell：在开始菜单搜索 PowerShell 并打开。安装时如果弹出系统权限确认，按提示允许。
  2. 先看有没有 winget： 
    winget --version
    打印出版本号就跳到第 3 条。提示"无法识别"就去 Microsoft Store 搜"应用安装程序"，点更新或安装，装完关掉 PowerShell 重开再试。
    查看图示：Microsoft Store 里的“应用安装程序”页面
  3. 依次执行三行，每行回车等它装完再下一行，中间要你确认协议就按 Y 回车： 
    winget install --id Git.Git -e
    winget install --id OpenJS.NodeJS.LTS -e
    winget install --id GitHub.cli -e
  4. 装完关掉 PowerShell 重新打开，这次不需要管理员。
winget 实在装不上？用官网安装包

三个都是"下载、双击、一路下一步"，装完重开 PowerShell：

  • Git：git-scm.com/download/win，点 Click here to download。
  • Node.js：nodejs.org，选 LTS，系统选 Windows，下载 .msi。
  • gh：cli.github.com，Download for Windows。
查看图示：git-scm.com 的 Windows 下载页
查看图示：nodejs.org 的下载页

Linux（Ubuntu / Debian）

  1. 打开终端，执行（会要你的密码，输入不显示是正常的）： 
    sudo apt update && sudo apt install -y git curl
  2. 打开 Node.js 官方下载页 ↗，选择 LTS → Linux → nvm，按页面命令安装。安装 nvm 后，按提示加载环境或重新打开终端，再安装 Node.js。
  3. gh 按官方说明安装：install_linux.md，使用 Debian / Ubuntu (apt) 一节的命令；其他发行版按对应章节安装。
完成标准：关掉终端，重新打开一个（让安装后的环境变量生效），执行： 
git --version
node --version
gh --version
每次执行一条，三条都显示版本号。Node.js 使用受支持的 LTS（长期支持）版本。

常见问题：提示 command not found 或"无法识别"，先检查安装是否成功，再重开终端；Windows 还不行就重启电脑。

准备工作环境第 5 / 11 步 · 约 5 分钟

让终端认识你的 GitHub

浏览器登录和终端登录是两回事。这一步让电脑能下载公司流程。

1. 在终端发起登录

gh auth login -h github.com -p https -w

这条命令已选好 GitHub.com、HTTPS 和浏览器登录，部分选择题会自动跳过。若询问是否用 GitHub 凭据登录 Git，选 Yes。

  1. 终端显示一次性的 8 位代码，按回车打开浏览器。
  2. 用绑定给 Morpheus 的 GitHub 账号登录，输入这次终端给的代码，按提示授权。
  3. 回到终端，看到 Logged in as 和你的用户名。
这是 GitHub CLI 的授权，与之前 Morpheus 的授权各做一次，代码不能混用。

2. 让 Git 使用同一份登录

gh auth setup-git
完成标准
gh auth status

显示已登录 github.com，当前账号与你绑定给 Morpheus 的一致。

浏览器没打开，或登录错账号？

浏览器没打开：手动前往 GitHub 设备授权页 ↗，输入终端本次显示的代码。过期就重新执行登录命令。

登录错账号：重新运行上面的登录命令，在浏览器确认使用正确账号，再运行 gh auth status 检查。

准备工作环境第 7 / 11 步 · 约 10 分钟

让 AI 助手在电脑上就位

把 Claude Code 装进终端，再登录你的订阅账号。

先在上方选择安装用的电脑系统，即可看到安装命令。

macOS 终端

Linux 终端

curl -fsSL https://claude.ai/install.sh | bash

按安装结束的提示处理 PATH，然后关掉终端重新打开，执行：

claude

第一次运行它会问你几个问题：

  1. 选配色，随便选，回车。
  2. 登录方式选 Claude account with subscription（用你「准备 Claude 账号」的订阅账号），不要选 Console。

  4. 它可能问是否信任当前文件夹，先确认路径是你准备工作的目录，再同意。之后出现一个可以打字的对话框，说明成了。先按 Ctrl + C 两次退出，安装公司流程后再回来。
完成标准：刚才能进入对话，退出后执行 claude --version 能打印版本号。

卡住：先重开终端，检查安装输出中的 PATH 提示，或对照 官方安装说明 ↗。

Windows 提示脚本策略限制？

准备工作环境第 8 / 11 步 · 约 5–10 分钟

在终端里用上 Codex

Codex CLI 是另一个 AI 工作入口，使用你自己的 ChatGPT 账号登录。

先准备自己的 ChatGPT 账号。

打开 ChatGPT ↗ 注册或登录，确认账号有 Codex 使用权限。需要订阅或升级时，先和引路人确认方案与报销要求；已有可用账号就直接使用。

1. 安装 Codex CLI

先完成 基础工具安装。已有 Node.js 的电脑可以在普通终端逐条执行：

npm install -g @openai/codex

装完重开终端，检查版本：

codex --version

2. 用 ChatGPT 账号登录

codex login

在浏览器按提示登录自己的 ChatGPT 账号并授权，完成后回到终端。使用个人账号的同事选择 ChatGPT 登录即可。

完成标准
codex login status

显示已登录，且 codex --version 能打印版本号。

安装失败、没有权限或找不到 codex？

先重开终端。Windows 若 npm.ps1 被脚本策略阻止，把安装命令中的 npm 改成 npm.cmd。macOS / Linux 若 npm 提示 EACCES，可以改用 官方独立安装方式 ↗；不要直接给 npm 安装命令加 sudo。

仍然失败，把安装报错和系统信息发给引路人。

开始和 AI 工作第 10 / 11 步 · 约 5 分钟

把公司流程交给 AI

安装入门插件，让 AI 知道公司的流程，以及该怎么带你完成。

安装前，请确认三件事
  • GitHub 的组织邀请已接受。
  • Git、Node.js、gh 已安装，终端已登录正确的 GitHub 账号。
  • Claude Code、Codex CLI 和 Codex Desktop 已安装并登录。

还在等审批？回到 「加入公司组织」 查看邀请。

在普通终端运行

如果还在与 Claude 或 Codex 对话，先按 Ctrl + C 退出，再粘贴这条命令：

npx github:Ali-Matrix-Technologies/ali-sop

出现 Ok to proceed? 时，按 y 回车。安装器会检查前置、同步流程库、分别为 Claude Code 和 Codex CLI 安装插件并验证。

完成标准：最后显示「完成」，Claude Code 和 Codex 两端验证通过，没有 ✘ 失败项。若出现「部分失败」，先按失败项提示处理。
报 404、没权限，或找不到 npx？

404 / 没权限：检查 邀请是否已接受，再用 gh auth status 检查是否登录同一个账号。

找不到 npx：回到 基础工具 检查 Node.js，装好后重开终端。Windows 若提示 npx.ps1 被执行策略阻止，可把命令开头的 npx 换成 npx.cmd 再运行。

开始和 AI 工作第 11 / 11 步 · 约 2 分钟

接下来，和 AI 一起做

账号和工具准备好了。让 AI 带你走进公司的工作方式。

1. 选择一个 AI 入口，重新打开

安装插件后重新启动，在新会话中加载公司流程。

claude

也可以在终端运行 codex，或重新打开 Codex Desktop。在桌面版的插件列表中检查公司插件是否已启用；如果没有，先使用 CLI 并联系引路人排查。

2. 在 AI 的对话框里说

STAY CONNECTED

先装 Telegram，联系上团队

公司沟通、入职通知和求助都在 Telegram。先在手机登录，再把同一个账号连到电脑。

1. 手机安装并登录

从 Telegram 官方应用列表 ↗ 进入 iOS 或 Android 的下载入口。打开应用，用自己的手机号按提示完成注册或登录。

2. 安装电脑客户端

打开 Telegram Desktop 官方下载页 ↗，选择 macOS、Windows 或 Linux，下载并安装。

启动桌面端，按界面提示用手机中的 Telegram 扫码登录，或选择手机号登录。确认手机和电脑使用同一个账号。

3. 找到引路人，加入公司群

把你的 Telegram 用户名私下告诉引路人，请对方拉你进群。群里只有「求助」和「公告」两个入口：有问题到「求助」，团队通知和流程更新看「公告」。请引路人发给你 Morpheus 的名片或私聊入口，之后按 加入公司组织 绑定 GitHub。

完成标准：手机和电脑都能打开 Telegram，用同一个账号看到消息，并能联系到引路人。
收不到验证码或无法连接？

按登录页面提示检查验证码接收方式；已登录的 Telegram 设备也可能收到登录消息。网络不可用时联系引路人确认公司网络方案，不要把登录码转发给别人。

INFRASTRUCTURE ACCESS

Teleport：访问公司资源的入口

公司入口尚未上线 · 暂不计入今天的完成进度

先了解用途。安装版本、公司连接地址和岗位权限，由管理员在上线后提供。

Teleport Connect 是桌面客户端，tsh 是终端客户端；两者用于访问公司授权给你的服务器、数据库等资源。

入口开通后，按这个顺序准备

  1. 向管理员确认公司入口和匹配的客户端版本。
  2. 通过 官方 Teleport Connect 安装说明 ↗ 下载对应系统的客户端：macOS 用 .dmg，Windows 用 .exe，Linux 按发行版使用 .deb / .rpm。
  3. 在 Connect 添加管理员提供的公司入口，按公司指引使用 GitHub 登录。
  4. 需要在终端访问资源时，按官方说明把 Connect 自带的 tsh 加入 PATH；然后重开终端检查。
tsh version
tsh status
开通后的完成标准：Connect 能登录公司入口，且能看到自己已获授权的资源；使用 CLI 时，tsh status 显示对应的登录状态。
已经安装，为什么还看不到资源？

安装客户端不会自动获得公司权限。入口上线后，按岗位需要私聊 Morpheus 发 /request 申请访问，审批完成后再检查。

GOOD TO KNOW

这些词是什么意思？

终端 / PowerShell
输入文字命令、让电脑执行操作的窗口。PowerShell 是 Windows 上常用的命令环境。
Git / GitHub
Git 是电脑上的修改记录工具；GitHub 用来在线共享代码和流程，并管理访问权限。
两步验证（2FA）/ 恢复码
两步验证在密码之外增加一次身份验证；恢复码用于无法使用验证器时恢复访问，要安全保存。
Homebrew / winget
分别在 macOS、Windows 上用命令安装软件的工具。
Node.js / npm / npx
Node.js 是运行工具的环境；安装它时一般会同时装好 npm 和 npx，npx 可以用一条命令运行安装器。LTS 表示长期支持版本。
GitHub CLI（gh）
让你在终端中登录、操作 GitHub 的工具。
Claude / Claude Code
Claude 是 AI 服务，Claude Code 是在电脑上协助你完成工作的 AI 工具，使用你的 Claude 账号登录。
SOP / 插件
SOP 是「这件事怎么做」的标准流程。公司插件让 AI 能读取这些流程并带你执行。
Codex CLI / Codex Desktop
Codex 的终端入口和桌面工作区，使用 ChatGPT 账号。安装指引在 工具箱。
Teleport Connect / tsh
访问公司基础设施的桌面与终端客户端。当前公司入口尚未上线，等管理员通知再连接。
Morpheus / 引路人
Morpheus 是公司 Telegram bot，处理入职和权限申请；引路人是拉你进群、帮助你开始的同事。
